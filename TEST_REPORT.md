## 2. Замечания по результатам проверок

- Даты публикации в шапке статей показаны в формате 2026-10-30 на всех языках. Для русской и сербской версий привычнее "30 октября 2026", но формат однозначен и не ошибочен.
- Оценка времени чтения считается по числу слов и может быть оптимистичной.
- В статье о торговых сетях таблица на русском языке на узком экране прокручивается по горизонтали внутри своего блока. Это сделано намеренно, чтобы страница целиком не прокручивалась.

## 3. Что не проверялось

1. Скорость и оценки Lighthouse (производительность, доступность, лучшие практики, SEO). Никаких цифр в пакете нет, и их заявлять нельзя без измерения на опубликованном адресе.
2. Автоматический аудит доступности (например, axe) и проверка экранным диктором. Контраст и размеры шрифтов выбраны по правилам дизайна, но отдельным инструментом не измерялись.
3. Реальные телефоны и браузеры, кроме Chromium (Safari, Firefox, Edge): не проверялись.
4. Rich Results Test Google и валидатор Schema.org: разметка проверена только на корректность JSON и соответствие видимому тексту.
5. Внешние ссылки (источники в статьях): адреса получены при чтении источников в ходе исследования, но массовая автоматическая проверка ответа каждого адреса на день сборки не выполнялась.
6. Workflow GitHub Actions ни разу не запускался: репозиторий не создавался. Корректность файла проверена чтением; первый запуск возможен только после создания репозитория владельцем.
7. Индексация, позиции в Google, Яндексе и Bing, показы и клики: сайт не опубликован, доступов к Search Console, Bing Webmaster Tools и Яндекс Вебмастеру нет.
8. Ответы ChatGPT, Gemini, Perplexity: не снимались. Цитируемость сайта этими системами не проверена и не гарантируется.
9. Частотность запросов (Wordstat, Keyword Planner, Trends): данные получить не удалось.
10. Вычитка русских и сербских текстов носителями языка и юридическая вычитка статей: не проводились. Список вопросов для вычитки в `README.md`, разделы 8 и 9.
11. Работа браузера Chrome с пометкой "Dima" для чтения профиля LinkedIn: браузер был недоступен, профиль на сайте не копировался.
